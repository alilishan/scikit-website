# Scikit

Website, brand and content for **Scikit** (scikit.com.au): websites, software and cloud for Australian small businesses.

| Folder | What's in it |
|---|---|
| `website/` | The Next.js site (deployed to Vercel with Root Directory = `website`). See `website/README.md`. |
| `content/` | Website copy, pricing research, SEO/GEO strategy and shareable PDFs. |
| `branding/` | Logo set and the Claude Design handoff the site is built from. |
